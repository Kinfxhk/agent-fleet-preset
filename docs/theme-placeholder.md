# Theme placeholder · agent-fleet-preset

**M0：** 只有主題**佔位**，不是完整白標 UI，亦**不**像素抄任何商業 Bot 介面。

## 用途

- 標示 Fleet 預設可掛自訂 CSS／tokens 的位置（後續里程碑）。
- 示意圖：[`docs/images/fleet-placeholder.svg`](images/fleet-placeholder.svg)

## 建議（後續，不在這個 M0 實作）

1. 自管 tokens（例如獨立 `tokens-*.css`），不綁供應商產品殼。
2. 公開品牌名用你自己的白標；技術相容寫「DSH」。
3. 不把競品截圖／字串／圖標入庫。

## 現在可以做

- 跟 `profiles/default/preset.json` 裝插件清單。
- 用 `agent-soul-pack` 模板做人設種子。
- 用 `agent-home-recipes` 健康檢查習慣。
